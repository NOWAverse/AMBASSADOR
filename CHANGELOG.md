# Changelog

## v0.3 — посол знает только свою папку · точная установка
- `AGENTS.md`: посол знает только SEED и то, что впишет владелец; первый запуск — сам готовит `USER.md` и `SOURCE.md` в `outbox/`; правило «одна заявка — один человек» (совладельцы подают сами); проверка блока по `CHECKLIST` и коду регистратора SEED; дополнительные права и обновление из репозитория только по просьбе владельца.
- `USER.md`: со-Правители, строка «Дополнительные права».
- Навык v0.3: точные пути к SEED (`templates/`, `CHECKLIST`, `registrar/check.py`), первый запуск, совладельцы.
- `INSTALL.md`: таблица зон доступа, точный рецепт для OpenClaw, раздел D (одна команда для одного репозитория), D2 (обновление по просьбе владельца).
- Новое: `config/openclaw-agent.example.json` — права агента.
- `SECURITY.md`: «посол знает только свою папку», заявки других людей.
- `TEST.md`: 10 проверок, добавлены «ничего лишнего не знает», «свои правила не меняет», «права в конфиге».
