# Как предложить правку

Репозиторий публичный: предложить правку может любой человек с аккаунтом GitHub.

1. Нажми **Fork** (соавторы могут сделать ветку прямо здесь) и внеси изменение.
2. Открой pull request. В описании: что изменилось, зачем, как проверил.
3. Не добавляй данные бизнеса, людей, ключи, адреса, пути, суммы денег.
4. `main` защищён: изменения только через pull request и только после одобрения владельца (файл `.github/CODEOWNERS`). Всё, что попадает в `main`, после обновления становится правилами настоящих ИИ-послов — поэтому каждый PR читается целиком.
5. Для изменений навыка добавь строку в `CHANGELOG.md`.

Предложения по правилам и уровням NOWA идут в повестку Совета, а не напрямую в этот репозиторий.
