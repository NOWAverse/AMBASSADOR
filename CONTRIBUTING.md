# Как предложить правку

1. Сделай ветку от `main` и внеси изменение.
2. Открой pull request. В описании: что изменилось, зачем, как проверил.
3. Не добавляй данные бизнеса, людей, ключи, адреса, пути, суммы денег.
4. Слияние делает человек-администратор. Прямой push в `main` не используется.
5. Для изменений навыка добавь строку в `CHANGELOG.md`.

Предложения по правилам и уровням NOWA идут в повестку Совета, а не напрямую в этот репозиторий.
