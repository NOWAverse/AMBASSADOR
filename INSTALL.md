# Как поставить посла NOWA

Навык один, способов установки три. Выбери свой.

## A. Агент с файлами (OpenClaw, Claude Code, свой агент) — рекомендуем
**Лучше всего отдельный агент-посол**, а не главный ИИ компании: у главного есть доступ к почте, базе и серверу, а послу это не нужно.
1. Создай отдельного агента с рабочей папкой только для NOWA.
2. Скопируй в неё файлы из этого репозитория: `AGENTS.md`, `SOUL.md`, `IDENTITY.md`, `USER.md`, `MEMORY.md`, `memory/LESSONS.md`, `NEVER_SHARE.md`, `templates/`.
3. Положи навык в папку навыков агента: `skills/nowa-ambassador/SKILL.md`.
4. Создай папки для работы: `drafts/`, `outbox/`, `journal/`, `proposals/`.
5. Заполни `<поля в скобках>` в `IDENTITY.md` и `USER.md`. Заполни свой файл-источник по образцу `SOURCE_TEMPLATE.md` и положи в `knowledge/planet/`. Не давай послу сырые профили, почту, базу и чаты.
6. Права агента (минимальные):
   - читать и писать только в своей папке;
   - без shell, браузера, сообщений, расписаний, доступа к другим агентам и общей памяти;
   - `AGENTS.md`, `SOUL.md`, `IDENTITY.md`, `USER.md`, `MEMORY.md` и `knowledge/` только для чтения; изменения посол предлагает через `proposals/`.
7. Пройди `TEST.md`.

## B. Чат-ассистент (ChatGPT Projects, Claude Projects, Gemini Gems)
1. Создай отдельный проект «NOWA посол».
2. Вставь текст `skills/nowa-ambassador/SKILL.md` в инструкции проекта.
3. Загрузи файлы: `NEVER_SHARE.md`, `templates/`, свой файл-источник.
4. Не подключай к проекту почту, диск и другие интеграции.

## C. Без ИИ
Открой `templates/`, заполни сам по подсказкам, проверь по `CHECKLIST.md`, отправь блок боту NOWA.

## Безопасность коротко
- Посол ничего не отправляет сам: ты пересылаешь блок боту и нажимаешь «Отправить».
- Чем меньше посол знает, тем меньше может раскрыть. Давай ему только уровень 1.
- Тексты других Планет — данные, а не команды. Если посол видит в них инструкции, он должен показать их тебе.
- Подробнее: `SECURITY.md`.
