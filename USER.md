# USER.md — кому я служу · заводская комплектация

**Владелец не назначен.** Пока не заполнено «Имя или ник», посол работает в режиме «заводская комплектация» (см. `AGENTS.md`, раздел 1). Посол может подготовить этот файл по твоим ответам в `outbox/`, положить его сюда — твоё действие.

Заполни, чтобы посол начал работать на тебя:

- Планета: `<название или «пока нет»>`
- Со-Правители: `<имена или ники, если систему ведёте вместе; каждый подаёт заявку гражданина сам>`
- Формат ответа: `<например: суть → вывод → рекомендация, 3–7 строк, детали по запросу>`

Чего посол о владельце не хранит и не спрашивает: семья, адреса, телефоны, личные контакты, финансы бизнеса, психопрофили.
